2.2 Correlación no lineal

2.2.2 Aplicaciones

Inicio 1. Introducción 2. Chi-cuadrada 3. Interpretación 4. Medidas de asociación 5. Aplicaciones Ejercicios

Marketing

Pregunta: ¿El género del cliente se asocia con el tipo de producto comprado?

  • Tabla género × categoría de producto.
  • \(\chi^2\) + V de Cramer; gráficos de barras apiladas o agrupadas.
  • Uso: segmentación y mensajes diferenciados.

Salud pública

Pregunta: ¿Hay asociación entre hábito de fumar (sí/no) y diagnóstico de cierta enfermedad (sí/no)?

  • Tabla 2×2; \(\chi^2\) o Fisher; odds ratio como complemento.
  • Cuidado: no afirmar causalidad solo con datos observacionales.

Educación

Pregunta: ¿El turno (matutino/vespertino) se asocia con aprobar/reprobar una asignatura?

  • Resultado útil para organización académica.
  • Revisar confusoras: carga laboral, edad, carrera.

Recursos humanos

Pregunta: ¿El departamento se asocia con el nivel de satisfacción laboral (bajo/medio/alto)?

  • Tabla r×c; V de Cramer para la fuerza.
  • Residuos para ver qué departamentos se desvían más.

Calidad / operaciones

Pregunta: ¿El turno de producción se asocia con la presencia de defectos (sí/no)?

  • Si hay asociación, priorizar inspección o capacitación en el turno problemático.

Relaciones numéricas no lineales (recordatorio aplicado)

Si dos variables son numéricas y el scatter no es lineal:

  • No concluir “no hay relación” solo porque Pearson es bajo.
  • Probar Spearman/Kendall si la tendencia es monótona.
  • Considerar transformaciones (log) o modelos no lineales.

Plantilla de reporte

«Se evaluó la asociación entre género y preferencia de producto mediante una prueba de chi-cuadrada de independencia (χ² = 11.67, gl = 1, p = 0.0006, n = 140). Se rechaza la hipótesis de independencia. La fuerza de la asociación fue débil-moderada (φ ≈ 0.29). El análisis es observacional y no implica causalidad.»
